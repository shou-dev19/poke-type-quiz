スライダーを左右にドラッグすると、同じ問題の改修前（左）と改修後（右）を見比べられます。

プレイの流れで比べる

改修前後で同じ乱数シードを使い、同じ問題が出た状態で撮影しています。

  1. 1START

    スタート画面

    • グラデーション文字のタイトル → 立体影つきのロゴ風タイトル
    • 3セット複製で揺れ続けるアイコン列 → 一時停止できるシームレスなマーキー
    • 絵文字の箇条書き → アイコン付きの4ステップのルール
  2. 2QUESTION

    問題画面

    • 浮いた進捗・難易度・スコア → 1本のHUDバー
    • ⚡ 絵文字をはさんだ2つの箱 → タイプカラーで縁取った VS 対戦カード
    • 白い箱の選択肢 → 倍率ごとに色味を変えた、押し込める立体ボタン

    モバイルは難易度「むずかしい」（6択・複合タイプ）

  3. 3ATTACK

    攻撃アニメーション

    • 黒80%のオーバーレイで裏の画面が透ける → タイプ色の集中線が入った対戦ステージ
    • 細い帯と小さな丸の粒 → 攻撃側から防御側へ飛ぶタイプ専用のSVG
    • 結果テキストが防御側アイコンに重なる → 結果専用エリアを分けて重なりを解消

    モバイルは攻撃側を下、防御側を上に置いた縦の対面

    回答から約1秒後、技エフェクトの最中

  4. 4EXPLAIN

    解説パネル

    • 色文字の「正解！」 → 弾んで出る正解・不正解バッジ
    • テキストだけの複合タイプ計算 → アイコンで書いた式と 0.5 × 1 = 0.5 の掛け算
    • 🏃 絵文字のボタン → 画面の主役になる「次の問題へ」ボタン

    モバイルの画面は縦にスクロールできます

  5. 5RESULT

    結果画面

    • グラデーション文字の羅列 → 0からカウントアップする正答率リング
    • 素のカード3枚 → アイコン付きの統計チップ
    • 主と副の区別が弱いボタン → 「もう一度」を主役にしたボタンの組

    難易度「かんたん」5問を解き終えた状態

動きで比べる

回答してから解説パネルが出るまでを録画しました。どちらも同じ問題で、「準備 → 技エフェクト → 結果表示」の3フェーズ構成は変えていません。

回答からのタイムライン（ms）

BEFORE
準備 技エフェクト 結果表示 →
AFTER
準備 飛翔・着弾 結果表示 →
0500100015002000

点線は着弾の瞬間（1000ms）。結果表示のあとは、クリックで解説へ進みます。操作がなければ、どちらも6秒で自動的に進みます。

18タイプ、6段階の着弾

技エフェクトは18タイプすべてに専用のSVGを描き、framer-motion の transform と opacity だけで動かしています。着弾の強さは、正解のダメージ倍率に応じて6段階で変わります。

ダメージ倍率ごとの着弾演出
×4こうかは ばつぐんだ！最大の衝撃リング、強い画面シェイク、ヒットストップ
×2こうかは ばつぐんだ！衝撃リングと画面シェイク
×1ダメージが とどいた！標準の衝撃とノックバック
×0.5こうかは いまひとつ…小さなリングと弱いノックバック
×0.25こうかは いまひとつ…リングだけのさらに弱い着弾
×0こうかが ないようだ…盾のアイコンで攻撃を弾く

変えなかったこと

  • 出題と採点のロジック。App.tsx・quizLogic.ts・pokemon.ts に差分はありません
  • 画面の文言、難易度と問題数の選択肢、選択肢のテキスト
  • 3フェーズのアニメーション、結果表示前はクリックで進めないこと、6秒での自動遷移
  • 既存のユニットテスト37件（テストコードは無修正で全件通過）
